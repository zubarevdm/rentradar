# RentRadar

Парсер «вкусных» (недооценённых) предложений по аренде жилья с автоматической
публикацией структурированных постов в Telegram.

> Полный план проекта (формат «PhD»): см. одобренный план в
> `~/.claude/plans/` или раздел [Дорожная карта](#дорожная-карта) ниже.

## Что это

Агент, который:
1. собирает объявления об аренде по заданным пользователем критериям (MVP — Циан);
2. считает **TastyScore** — степень «вкусности» (недооценки относительно рынка);
3. публикует лучшие лоты в Telegram-канал через официальный Bot API.

## Архитектура (конвейер)

```
Collectors → Normalizer → Dedup + Fraud filter → Scoring Engine → Publisher
   (Cian)      (Listing)                          (TastyScore)     (TG Bot)
        ▲                                                              ▲
     Scheduler ──────────────── Storage (SQLite → Postgres) ──────────┘
```

Слои слабо связаны: добавить площадку = новый `Collector`-адаптер, ядро не трогаем.

## Структура кода

```
src/rentradar/
  config.py          # настройки (.env) + загрузка профилей поиска
  models.py          # доменные модели: Listing, ScoreBreakdown, SearchProfile
  interfaces.py      # контракты слоёв: BaseCollector / ScoringEngine / Publisher
  collectors/        # адаптеры площадок (cian — позже)
  scoring/           # движок «вкусности» (Глава 3)
  publisher/         # постинг в Telegram (Глава 4)
  storage/           # SQLAlchemy ORM + репозиторий
  pipeline.py        # оркестрация конвейера
  cli.py             # точка входа
```

## Дорожная карта

- **Глава 0** — каркас проекта (этот коммит). ✅
- **Глава 1** — `CianCollector` (сбор объявлений). ✅
- **Глава 2** — Normalizer + Storage + дедуп. ✅
- **Глава 3** — Market stats + Scoring Engine. ✅
- **Глава 4** — Telegram Publisher + шаблон поста. ✅
- **Глава 5** — Scheduler (`serve`, автопостинг по расписанию). ✅
- **Площадки** — `CianCollector`, `YandexCollector` (глобальный топ-5 со всех площадок,
  кросс-площадочный дедуп по `content_key`). ✅
- **Персональный бот (платный)** — пользователь настраивает фильтр (метро/район,
  цена, комнаты, время до метро) + интервал; бот шлёт новые совпадения в личку.
  Триал на N бесплатных отправок, оплата ЮKassa. Матчинг по центрально собранной
  БД (площадки не дёргаются на каждого юзера). ✅
- **Глава 7+** — Авито (нужны прокси), Postgres, VPS/служба 24/7.

## ⚠️ Правовая рамка

Парсинг площадок нарушает их ToS; публичный репостинг чужих фото/данных — зона
риска. На проекте: ссылка на первоисточник, минимальное хранение фото, умеренный
rate-limit. **До монетизации** — консультация юриста и оформление ИП/самозанятости.
