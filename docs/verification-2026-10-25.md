# Правки от 25.10.2026 — реализация и проверка

## Результат

- Один пробник на ровно 24 часа после успешной проверки канала, с окончанием по
  времени; нет коммерческого ограничения по числу объявлений. Проверки, перезапуски
  и пауза не продлевают пробник. В интерфейсе даты и время по Москве.
- Единая политика доступа для рассылки, создания фильтра, статуса, статистики и
  lifecycle. Оплата и бонусы складываются с остатком и сохраняются на паузе;
  оставшийся пробник не превращается в замороженные часы.
- Четыре тарифа из одного каталога, ручное подтверждение `/paid`, уникальный
  журнал операций, атомарные продления и реферальная награда. `/grant` — подарок.
  Старый Telegram Payments не может открыть доступ.
- Рефералы: 12 часов за проверку канала и первый сохранённый поиск, ещё 48 часов
  за первую подтверждённую оплату. Порядок событий произвольный; начисления
  однократны, существующие награды и пригласившие сохраняются.
- Метро Москвы и МЦК: локальная топология линий, выбор точной станции с линией,
  соседи до трёх перегонов, кольца и развилка Филёвской линии, несколько групп,
  снятие станции и объединение без дублей. Кнопки содержат устойчивые ID и версию
  состояния; старые клавиатуры отклоняются.
- В личных и публичных подписях есть стоимость заезда, известные платежи и явные
  уточнения неизвестных условий. ЖКУ показаны отдельно. HTML экранируется;
  длинная подпись сокращает второстепенные блоки, сохраняя деньги, фото и источник.
- Обновлены приветствие, справка, поддержка, статус, подписка, рефералы,
  уведомления, статистика, README, пример конфигурации и админская справка.

## Применение и работа администратора

Код подготовлен; деплой, боевой сервис и рабочая миграция не запускались.
При обновлении останови сервис, сохрани резервную копию SQLite и выполни
обычный `rentradar init-db` с нужной конфигурацией либо запусти обновлённый сервис.
`SqlStorage.init()` применяет добавление колонок и однократный backfill с версией
`access_20261025`. Прежние пользователи без доступа получают только право на
24 часа; отсчёт начнётся после следующей успешной проверки канала. Повторная
инициализация не расширяет круг и не сбрасывает выдачу. Пользователи с текущим
доступом или остатком на паузе не получают отложенный дополнительный подарок.

После проверки реального перевода администратор из настроенного списка отправляет:

```text
/paid 123456789 3d pay_20261025_001
```

Один перевод — один уникальный `operation_id`. При повторной попытке используй тот
же номер; для другого перевода — новый. Конфликт пользователя/тарифа отклоняется.
`/grant 123456789 3` — отдельный подарок на 72 часа, без платёжной истории и
реферальной награды за оплату. Пользователь видит настроенный `admin_contact`;
этот же контакт используется для поддержки.

## Ограничения

Остаются исходные ошибки mypy; полный type check не объявляется успешным.
Есть предупреждения Python 3.12 о стандартном адаптере datetime в sqlite3.
Расписание lifecycle сохранено суточным: отключение доступа точно по времени,
а напоминание приходит при очередном существующем проходе.
Справочник метро статичен; источник — официальный PDF Москвы, редакция
29.12.2025, проверенная 25.10.2026. Его обновление выполняется вручную; МЦД
не включены. Данные JSON/БД из боевого сервиса не использовались для справочника.

Повтор `/paid` может повторить уведомление, но не начисление. При откате к старому
коду после новых оплат необходимо отдельно планировать сохранение новых полей и
журнала. Автоматическая обработка переводов и внешние платёжные провайдеры
согласно заданию не подключались.
